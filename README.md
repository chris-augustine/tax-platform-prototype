## What's Real and Simulated

The application's core front-end workflow is functional and includes role-based navigation, which can be explored through the interactive Individual Taxpayer → Tax Preparer → Tax Reviewer workflow. The individual taxpayer and tax preparer are able to exchange messages with each other, with the state and context of their conversation maintained across views. Furthermore, using React state/context, the individual taxpayer's progress updates as actions such as document submission, return preparation, and quality review are kept track of. The Tax Preparer interface specifically demonstrates AI-review interactions, source-document traceability, value correction and verification, and a handoff to the Tax Reviewer. Search and filtering across a large generated dataset are also functional.

React state/context and mock data are used to simulate the behavior of a backend. Authentication, persistent database storage, tax calculations, actual file transfer and processing, OCR/AI extraction, confidence metrics, and filing are simulated. Finally, Business Owner, Firm Admin, and Seasonal Staff views are primarily static demonstrations designed to showcase role-aware experiences.
